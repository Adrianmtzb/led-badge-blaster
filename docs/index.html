Instalar

Install

El firmware se descarga en tu navegador y se escribe directo al dispositivo por Web Serial. No pasa por ningún servidor.

The firmware downloads into your browser and is written straight to the device over Web Serial. It never goes through a server.

  1. Conecta el ATOM Lite por USB.

    El cable de datos que venía con la placa; algunos cables de carga no llevan datos.

  2. Cierra el monitor serie.

    Si el Arduino IDE o un screen tienen el puerto abierto, la instalación falla.

  3. Pulsa Instalar y elige el puerto usbserial.

    Tarda menos de un minuto. Al acabar, el dispositivo arranca solo. El panel muestra abajo la versión que quedó instalada, para comprobar que coincide con la de aquí.

  1. Plug the ATOM Lite in over USB.

    The data cable that came with the board; some charging cables carry no data.

  2. Close the serial monitor.

    If the Arduino IDE or a screen holds the port open, the install fails.

  3. Press Install and pick the usbserial port.

    It takes under a minute. When it finishes, the device boots on its own. The panel shows the installed version at the bottom, so you can check it matches the one here.

Primer arranque

First boot

El cable ya no hace falta: el dispositivo levanta su propia red WiFi y sirve el panel de control.

You can unplug the cable now: the device brings up its own WiFi network and serves the control panel.

  1. Conéctate a la red LED-Badge-XXXX.

    La clave es ledbadge. Las X son los últimos bytes de su MAC.

  2. El panel se abre solo.

    Si tu móvil no lo detecta, entra a http://192.168.4.1.

  3. Toca un color y ya está emitiendo.

    En Red y ajustes puedes darle tu WiFi; luego responde en http://led-badge.local.

  1. Join the LED-Badge-XXXX network.

    The key is ledbadge. The Xs are the last bytes of its MAC.

  2. The panel opens by itself.

    If your phone does not catch it, go to http://192.168.4.1.

  3. Tap a color and it is already transmitting.

    Under Network and settings you can give it your WiFi; after that it answers at http://led-badge.local.

El botón de la placa

The button on the board

Clic
Emite el efecto actual y avanza al siguiente.
Doble clic
Cambia de categoría.
Mantener 3 s
Olvida el WiFi y vuelve al portal.
LED de estado
Muestra el color del efecto seleccionado. Destella en blanco al emitir y en magenta al borrar las credenciales.
Click
Sends the current effect and moves to the next one.
Double click
Switches category.
Hold 3 s
Forgets the WiFi and goes back to the portal.
Status LED
Shows the color of the selected effect. Flashes white when transmitting and magenta when the credentials are cleared.

El catálogo

The catalog

Todos los efectos son tramas de color único: encienden el badge con un color y una envolvente, y no dejan rastro al apagarlo. Aparte, el panel lleva una pestaña avanzada, Canal, que sí escribe en la EEPROM del badge para cambiar a qué grupo responde: ese cambio es permanente y por eso va separado del catálogo.

Every effect is a single-color frame: it lights the badge with one color and an envelope, and leaves no trace once it is powered off. Separately, the panel carries an advanced tab, Channel, which does write to the badge's EEPROM to change which group it responds to: that change is permanent, which is why it is kept apart from the catalog.
